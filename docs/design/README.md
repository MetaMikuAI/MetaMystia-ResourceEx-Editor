# ResourceEx Editor 设计文档

本目录保存 ResourceEx Editor 的产品视觉规范与审计记录。`app/design/**` 是设计系统的程序实现目录，不存放说明文档。

## 文档索引

- [整站视觉规范](./resource-editor-visual-system.md)：规定页面层级、Token、组件、状态、响应式和代码所有权。
- [整站视觉审计](./resource-editor-visual-audit.md)：记录本轮 12 个路由的真实页面证据、问题分类和实施状态。

## 使用顺序

1. 修改页面前先查阅整站视觉规范，并复用规范指向的代码 owner。
2. 页面无法遵守规范时，先在规范的“例外登记”中说明原因、范围和退出条件，再实现局部差异。
3. 视觉修改后更新审计矩阵，并以相同视口和页面状态重新验证。
