# 依赖与工程配置

## 1. 依赖原则

- 参考项目依赖不能整表复制。
- 本项目每个直接依赖都必须有明确调用者和 owner。
- 选中的参考非业务文件若有直接依赖，默认同步该依赖；任何例外必须在偏差台账登记，不能扩展成通用策略。
- 编辑器业务依赖保留；参考项目账户、服务端、推荐、PWA、旧浏览器依赖不引入。
- 当前 `node_modules` 不能替代干净安装验证。

## 2. 运行时依赖

### 保留

- Next.js、React、React DOM；
- 目标核心闭包使用的 HeroUI Button、Card、Dropdown、Input、Modal、Navbar、Popover、ScrollShadow、Select、Switch、System、Theme、Tooltip；
- `framer-motion`（按 HeroUI 固定兼容版本）；
- `jszip`：ResourceEx ZIP 读取/写入；
- `file-saver`：浏览器导出下载。

### 新增直接声明

| 依赖             | 版本     | 目标直接调用者                | 原因                                       |
| ---------------- | -------- | ----------------------------- | ------------------------------------------ |
| `@heroui/input`  | `2.4.10` | Design Input/Textarea         | 替换当前草案 TextInput/TextArea            |
| `@heroui/select` | `2.4.10` | resourceEditor Select adapter | 替换 Dropdown 模拟 Select 并保留业务值契约 |

按 D15 不把 `client-only` 声明为目标直接依赖；Next 识别该边界标记，当前依赖树也已传递解析该包，不需要为正常 import 重复安装。

如果实施时调整 HeroUI 兼容组，必须先确认原样 patch 仍能由 pnpm 安装，不能手改 patch 迁就不兼容产物。

### 主题与 className 边界

迁移期调用者可继续通过现有 `cn` 转发入口工作；最终全部改为从 `@heroui/theme` 直接导入并删除转发层。参考主题实现的依赖解析例外只由 D12 定义，不能扩展成通用的隐式依赖策略。

目标无调用者后同时删除：

- `@heroui/avatar`；
- `@heroui/badge`（不用于 editor 的内联状态标签）；
- `@heroui/link`；
- `@heroui/pagination`；
- `@heroui/snippet`。

### 不引入

- 账户/状态：`@davstack/store`、`broadcast-channel`、`idb`；
- 服务端/数据库：argon2、better-sqlite3、kysely、WebAuthn server；
- 推荐/目录业务：lodash、pinyin、uuid 等参考依赖；主题色阶不迁入无必要调用者的 memoize；
- PWA/兼容：abortcontroller polyfill、wicg-inert；
- 视觉业务：FontAwesome、QR、driver.js，除非后续本项目实际功能明确需要。

### 原样迁移的依赖 Patch

Patch 的包名、版本、文件名、原样复制规则和排除证据只有一个事实来源：[11-依赖 Patch 迁移矩阵](./11-依赖Patch迁移矩阵.md)。依赖配置只登记该矩阵选中的条目，不在本文重复维护数量或包清单。

## 3. pnpm

本迁移不把参考仓库的包管理布局当作同步对象。目标继续使用本项目的 pnpm linker、public-hoist、override 与 `onlyBuiltDependencies` 策略；与参考布局不同的必要解析边界只由偏差台账定义。

实施动作只有：

- 增加表中两项直接依赖；
- 删除 Avatar/Badge/Link/Pagination/Snippet wrapper 后，删除对应且已无调用者的 HeroUI 直接依赖；
- 原样复制并登记 Patch 矩阵选中的条目；
- 运行 `pnpm install` 更新 lockfile；
- 每次执行 `pnpm up && pnpm dedupe` 后审查 HeroUI/Motion 传递版本与 Patch 可应用性，不能只看直接依赖版本。

当前实施状态由 [06-实施状态与交接](./06-实施状态与交接.md) 维护；Patch 相关解析版本由 [11-依赖 Patch 迁移矩阵](./11-依赖Patch迁移矩阵.md) 维护，本文不重复现状快照。

## 4. TypeScript 与路径

迁移期：

```json
{ "paths": { "@/*": ["./app/*", "./src/*"] } }
```

`include` 同时列出 `app/**/*.ts`、`app/**/*.tsx`、`src/**/*.mjs`、`src/**/*.ts`、`src/**/*.tsx`，并继续覆盖根 `*.ts`/`*.mjs` 配置、`next-env.d.ts` 和 Next 生成类型。根 `app` 的完整 route 过渡壳必须与该配置在同一个切片建立。

最终：

```json
{ "paths": { "@/*": ["./app/*"] } }
```

- 保留当前严格选项；
- 全部 owner 迁完并删除 `src` 后，include 删除 `src/**`，保留根 `app`、实际配置/脚本、Next 声明和生成类型；
- `design/theme` 使用相对 import；
- 全局声明移至 `app/declarations`。

## 5. Tailwind 与浏览器目标

- 迁移期 content 同时包含 `./app/**/*.{ts,tsx}` 与 `./src/**/*.{ts,tsx}`；删除 `src` 后只保留前者；
- 保留当前 HeroUI 组件自动发现；
- theme import：`./app/design/theme`；
- 资源继续使用站点根路径；

## 6. Next 配置

- `output: 'export'` 无条件保留，不建立参考项目的 export/standalone/Node runtime 模式切换；
- 同步适用于纯 App Router 的 `reactStrictMode: true` 和 typed routes；
- 保持 PEM asset/source webpack rule；
- 按用户明确要求保留当前 `SKIP_LINT` 环境变量及其 ESLint、TypeScript、webpack memory 分支（D14）；默认未设置时仍执行完整构建检查；
- 不复制参考的 Server Action、headers、CDN/assetPrefix、analytics、self-hosted、build identity 或请求时环境配置；
- 保留 `next/font/google` 的 Noto Sans、Noto Sans Mono、Noto Sans SC 与既有 CSS 变量；
- Next Patch 将构建期 `fonts.googleapis.com`/`fonts.gstatic.com` 请求改到 `fonts.loli.net`/`gstatic.loli.net`；字体文件仍由 Next 在构建时写入 `_next/static/media`，浏览器运行时不请求字体服务；
- 不引入默认 `next/image` 优化服务；若未来出现 `next/image` 调用者，必须选择静态可用的 unoptimized/custom-loader 方案并单独审查；
- 不配置 Next rewrites/redirects/proxy。根 `/` 使用客户端 replace，extensionless route 与 404 由静态服务器处理；
- 环境变量只能在构建时内联公开常量，不能成为部署后的运行时配置源；
- 保留的每个实验项必须有静态构建调用理由。

### 静态服务器契约

产物目录为 `out/`，部署在 origin 根路径。外部服务器必须直接提供 `_next/**`、`assets/**` 和其他 public 文件，并把 `/info` 等 extensionless 路径解析到对应 `.html`。Nginx 的核心 fallback 形态为：

```nginx
location / {
	try_files $uri $uri.html $uri/ =404;
}

error_page 404 /404.html;
```

缓存、压缩、安全响应头和 MIME 类型由静态服务器配置，不写进 `next.config.ts`。若未来需要子路径部署，必须把 `basePath`、资源 URL、路由和导出夹具作为独立变更统一设计；本迁移按 origin 根路径验收。

- [ ] 两项新增直接依赖都能追溯到目标调用者；
- [ ] `pnpm exec tsc --noEmit`；
- [ ] focused Prettier；
- [ ] `pnpm build` 静态导出；
- [ ] `out/index.html`、12 个 route HTML、404、RSC payload、`_next/**`、`assets/**` 与 `_next/static/media` 字体完整；

- [ ] 构建期字体请求按 Next Patch 使用镜像域名；浏览器运行不依赖 Next Node server、请求时环境变量或远程字体服务；
- [ ] 全新依赖树下解析与运行成功。
