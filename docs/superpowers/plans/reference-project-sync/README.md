# 参考项目同步重构

## 任务目标

在保留 MetaMystia ResourceEx Editor 业务语义与工作流结果的前提下，同步参考项目适用的代码组织、设计系统、共享工具、基础样式、声明、工程配置与依赖治理。

参考项目是全栈应用，本项目则是纯客户端编辑器。目标产物始终为 Next.js `output: 'export'` 生成的 `out/` 静态文件，可由 Nginx 或等价静态服务器直接托管；参考项目的服务端运行模式不属于迁移目标。

目标结构：

```text
app/{declarations,design,domain,features,infrastructure,shared}
```

现有首层 UI/交互属于草案，不作为视觉兼容基准。布局、组件外观、响应式、焦点、滚动与操作反馈以参考项目的成熟实现为基线；ResourceEx 字段语义、编辑能力、URL、导入/导出产物与未保存保护是迁移不变量。

非业务能力采用“能力同源、业务适配”：

- 本项目实际需要的 Design、theme、shared 和 browser 能力以参考实现和行为为基线；
- 路由、数据、文案、业务 props、状态接入和 feature 组合按 ResourceEx Editor 业务重做；
- 不整包复制参考目录，不引入没有目标调用者的模块；
- 选中能力的实质偏差必须登记在 [10-非业务能力同步与偏差台账.md](./10-非业务能力同步与偏差台账.md)。

## 全局约束

- 保留全部 ResourceEx 编辑、导入、迁移、校验、资产管理、导出与未保存状态保护结果。
- 现有首层 UI/交互不是兼容基准；选中的非业务能力以参考实现为默认基线，所有实质偏差必须登记。
- 不引入账户、同步、管理后台、公告服务端、推荐、数据库、自托管发布、离线包或 Service Worker。
- `output: 'export'` 是不可放宽的运行边界；不引入 Server Action、请求时 Route Handler、cookies/headers、rewrites/proxy、Next Node runtime 或默认图片优化服务。
- 浏览器文件、ZIP、storage、Web Crypto 与下载能力必须位于 client boundary；Server Component 只能承担可在构建时确定的静态组合。
- 站点按 origin 根路径部署；`_next/**`、`assets/**` 和各路由 HTML 由外部静态服务器提供，缓存与响应头也由该服务器负责。
- 只支持最新稳定版浏览器；不移植旧浏览器 polyfill、Safari 旧 API fallback 或额外兼容层。
- 不新增仅用于转发的 barrel `index.ts`；业务代码导入实际 owner 的叶子模块。
- 依赖、工具链、patch 和非业务实现偏差分别以 [04-依赖与工程配置.md](./04-依赖与工程配置.md)、[10-非业务能力同步与偏差台账.md](./10-非业务能力同步与偏差台账.md) 和 [11-依赖Patch迁移矩阵.md](./11-依赖Patch迁移矩阵.md) 为唯一来源，不在总览重复维护。
- 保留工作区中已有的 staged、unstaged 和 untracked 内容。
- agent 运行的临时脚本、日志、截图、trace、安装副本、生成结果和其他非交付输出统一写入项目根目录 `.tmp/`，不得散落到源码目录或系统临时目录；可配置的任务专用缓存使用 `.tmp/cache/<tool>/`。任务结束时关闭会话、服务和进程并清理这些缓存目录；`.tmp/` 中的其他临时文件保留并列入交接，不阻塞任务完成，用户后续另行要求时再清理。
- 未经明确授权，不 stage、commit、amend、push、切换分支/工作树或创建 PR。
