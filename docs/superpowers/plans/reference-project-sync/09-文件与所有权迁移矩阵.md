## 8. 根配置与最终删除

目标根为 `app/` 后：

- 根 `app` route 过渡壳建立时，`tsconfig.json` alias 临时改为 `@/* -> ["./app/*", "./src/*"]`，include 与 Tailwind content 同时覆盖两棵树；
- 12 个业务 shell 统一位于 `app/(pages)/<route>/page.tsx`；括号组不进入 URL，根 `app/page.tsx` 和根 layout 保持独立，不新增无语义 group layout；
- 全部迁完并删除 `src` 后，alias/content/include 收紧到单一 `app`；
- Tailwind theme import 在 design owner 迁入时指向 `app/design/theme`；
- Next 的 PEM asset rule 保留；
- Next 同步 `reactStrictMode`/typed routes，并按用户明确要求保留现有 ESLint/TypeScript/webpack `SKIP_LINT` 分支（D14）；
- `src/` 只在全部调用者迁移完成、构建与运行验证通过后删除；
- 任何相交文件都先重读完整内容及 staged/unstaged diff，再做最小修改。

完成扫描：

```text
无 @/components、@/data、@/hooks、@/lib、@/types、@/utilities
无 @/design/ui/components barrel
无 @/design/ui/utils
app/** 无 ../
无只转发的 index.ts
除 beforeunload 外无 alert/confirm
无原生 dialog/showModal/close
URL.createObjectURL/URL.revokeObjectURL 只存在于 features/resourceEditor/client/assets 的持久 URL owner 与 infrastructure/browser/images/readImageDimensions.ts 的瞬时 URL owner
无 Server Action、请求时 Route Handler、cookies/headers、rewrites/proxy 或运行时 Node-only 依赖
```
