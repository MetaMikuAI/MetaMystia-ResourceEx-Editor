# 现状与差异清单

## 1. 本项目业务内核

当前源码位于 `src/`，包含 181 个 TypeScript/TSX 文件、2 个 SCSS 文件及业务资源。根 URL `/` 重定向到 `/info`；以下 12 个编辑 URL、数据语义和工作流结果是迁移不变量，当前草案 UI 的像素、布局和 wrapper props 不是不变量：

| 路由          | 业务能力                                               |
| ------------- | ------------------------------------------------------ |
| `/info`       | 资源包基本信息、依赖、ID 范围与签名信息                |
| `/character`  | 稀客/角色资料、立绘、精灵、羁绊与生成配置              |
| `/dialogue`   | 对话包、对话条目、分支/Goto/End、CG/BG/音频动作        |
| `/merchant`   | 商人和商品配置                                         |
| `/ingredient` | 食材编辑                                               |
| `/food`       | 料理编辑与预览                                         |
| `/recipe`     | 食谱编辑与料理预览                                     |
| `/beverage`   | 酒水编辑                                               |
| `/clothes`    | 衣服、肖像和像素精灵配置                               |
| `/mission`    | 任务节点、完成条件、奖励和后置节点                     |
| `/event`      | 事件节点、触发器、事件数据、奖励和后置节点             |
| `/asset`      | `assets/` 目录、文件上传/复制/移动/删除及对象 URL 预览 |

### 当前状态所有者

`src/components/context/DataContext.tsx` 同时负责：

- 空白资源包初始值；
- `ResourceEx.json`、`LICENSE.md` 和 ZIP 资产导入；
- 旧字段归一化与兼容迁移；
- 资产 Blob、对象 URL、虚拟目录、复制/移动/删除；
- 离页前未保存更改提醒；
- 导出前清理、排序、换行归一化和动作字段裁剪；
- JSON 引用资产与用户管理资产的 ZIP 回写；
- 文件名生成和未保存状态复位。

`src/components/common/validateResourcePack.ts` 当前混合纯领域规则、资产路径检查和 browser Web Crypto 验签；`src/lib/constants.ts` 与 `src/lib/crypto.ts` 分别拥有 Label/ID 规则和 RSA-SHA256 签名协议。这些属于本项目业务能力，目标必须拆分所有权，不能用参考项目的其他业务替换。

## 2. 当前结构问题

- `src/app` 之外按 `components`、`data`、`hooks`、`lib`、`types`、`utilities` 技术层平铺。
- `DataContext.tsx` 混合 archive I/O、迁移、资产状态、序列化和 React 生命周期。
- `src/design/ui/components/index.ts` 是宽 barrel；当前有 52 个文件从它导入。
- 至少 49 个文件从 `@/design/ui/utils` 导入迁移期 `cn` 转发层。
- 当前业务依赖参考项目已删除的 design barrel、`cn` 转发层、Navbar wrapper 和自制 Select wrapper，不能直接覆盖 `design/`。
- `src/types/*.d.ts` 混合全局声明与领域契约。
- 当前 `memoize` 只服务模块初始化时的固定主题色阶，目标将 `swapColorScale` 改为普通纯函数并保持调用处直接计算，删除缓存层；`safeStorage` 属于 browser infrastructure；`useMounted` 属于 shared React 生命周期。
- `globals.scss` 混合主题运行时、通用 utility、`.surface-pressable` 和棋盘背景等编辑器特有样式。

## 3. 参考项目所有权结构

参考源码直接位于根 `app/`：

- `app/design`：主题、设计偏好、HeroUI 包装组件、动效 hook；
- `app/domain`：领域数据、目录与规则；
- `app/features`：按用户能力组织的客户端/服务端功能；
- `app/infrastructure`：浏览器、HTTP、存储、环境、数据库等外部能力；
- `app/shared`：不依赖 domain/feature/design/infrastructure 的 React 和通用工具；
- `app/declarations`：环境、样式、DOM、工具链等全局声明。

架构重组提交 `291a16b8` 显示的迁移方向：

- `types` → `declarations`、`domain` 或具体 feature；
- `utilities` → `shared/utilities`、`infrastructure/browser` 或具体 feature；
- `hooks` → `shared/react`、`design/ui` 或具体 feature；
- `data` → `domain/data`；
- `components` → `design/ui` 或具体 feature；
- 页面只承担路由组合，业务 UI 下沉 feature。

参考项目约有 998 个 TS/TSX 文件，包含大量本项目不需要的业务，因此同步的是所有权结构与适用基础模块，不复制整个 `app/`。

参考项目同时包含账户、数据库、Server Action、请求时 Route Handler、多部署模式和服务端环境分支；本项目固定使用 `output: 'export'`，现有 12 个静态路由会生成独立 HTML/RSC payload，文件编辑、ZIP、storage、Web Crypto 和下载均在浏览器完成。参考的全栈 owner 只能用于理解依赖方向，不能迁入目标运行时。

## 4. 设计系统差异

`src/design` 与参考 `app/design` 的目录级 no-index diff 涉及 63 个差异文件：

- theme hook：`design/hooks/use-theme` → `design/theme/runtime`；
- color barrel 删除，`constants/index.ts` → `palette.ts`；
- 模块契约 `.d.ts` → 普通 `.ts`；
- rating 文件改为语义化命名；
- UI barrel、本地 `cn.ts`、Navbar wrapper、Select wrapper 删除；
- `cn` 统一来自 `@heroui/theme`；
- Modal、Popover、Tooltip、Button、Dropdown 和动效 hook 契约均有变化；
- 参考新增组件中部分依赖 FontAwesome、QR、站点元数据或参考业务，不应无条件移植；
- 参考 theme runtime 依赖 `safeStorage`，但媒体查询 helper 只为 Safari < 14，本项目改用原生标准 API。

### 当前实际使用面

- `@/design/ui/components`：52 个导入文件；
- `@/design/ui/utils`：49 个导入文件；
- `@/design/ui/hooks`：14 个导入文件；
- `@/design/utils`：2 个导入文件；
- `@/design/hooks`：1 个导入文件。

高风险调用面：

- Select 被 asset、recipe、ingredient、merchant、mission、event、dialog、character 等编辑器广泛使用；
- Modal 被公告、导出校验、资产选择、料理预览使用；
- Navbar wrapper 仅服务当前 App Shell，应移出 design；
- `cn` 在业务 UI 中广泛使用；当前转发层保证行为同源，最终机械迁移为直接从 `@heroui/theme` 导入。

补充 AST 调用面：

- Button：97 个 JSX 实例，分布于 31 个文件；
- Select：38 个 JSX 实例，分布于 20 个文件；
- Design Modal：4 个 JSX 实例，分布于 4 个文件；
- 原生 `<dialog>`：1 个调用文件（`IdRangeEditor.tsx`），目标统一迁为 Design Modal；
- Switch：6 个 JSX 实例，分布于 4 个文件；
- 原生 `alert`/`confirm`：35 个调用，分布于 20 个文件。

当前 Select 需要保留 `string | number | undefined` 受控值、sections、disabled item、description、`textValue`、尺寸、错误状态和菜单高度，但底层可直接替换为 HeroUI Select。完整组件与交互设计见 [07-UI与交互迁移设计.md](./07-UI与交互迁移设计.md)。
